# Support

## Questions

For general questions, open a GitHub Discussion if enabled, or create an issue with the `question` label.

## Bugs

For bugs, open a bug report using the issue template.

Please include:

- what you expected
- what happened
- steps to reproduce
- logs or screenshots, if useful
- your operating system
- Docker version
- whether you are using CPU or GPU

## Feature requests

For feature requests, open a feature request issue and describe:

- the problem
- the proposed solution
- the expected users
- alternatives considered

## Security issues

Do not report security vulnerabilities in public issues.

See [`SECURITY.md`](SECURITY.md).
