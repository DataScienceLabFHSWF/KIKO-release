# Phase 0 is complete when:

- [ ] Every Streamlit page has a React route.
- [ ] Every route has a role rule.
- [ ] Every route lists required API endpoints.
- [ ] Every route lists loading/error/empty states.
- [ ] P0 backend endpoints no longer expose `{}` or `Dict` in OpenAPI.
- [ ] Shared API error format is accepted.
- [ ] JWT expiration behavior is documented.
- [ ] CORS allowed origins are documented.
- [ ] UI parity checklist is reviewed by supervisor.
- [ ] OpenAPI can be used to generate reliable TypeScript types.
