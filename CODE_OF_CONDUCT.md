# 📜 Code of Conduct

## 🤝 Our commitment

We want KIKO to be a respectful, constructive, and welcoming project for contributors, users, researchers, and maintainers.

## ✅ Expected behavior

Participants are expected to:

- communicate respectfully
- give and receive feedback constructively
- focus criticism on ideas and code, not individuals
- respect different levels of experience
- document decisions clearly
- help keep the project understandable for new contributors

## 🚫 Unacceptable behavior

Unacceptable behavior includes:

- harassment, insults, or personal attacks
- discriminatory language or behavior
- publishing private information without permission
- deliberate disruption of discussions or pull requests
- knowingly submitting unsafe code, credentials, or private data

## ⚖️ Enforcement

Maintainers may remove comments, close issues, reject pull requests, or block participants who violate this code of conduct.

## 📣 Reporting

Report concerns privately to the maintainers listed in the repository README.

All reports will be reviewed with care and confidentiality.
